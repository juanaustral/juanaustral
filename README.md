## Cómo trabajo

1. **Entender.** Escucho, leo lo que hay y encuentro dónde se traba el proyecto.
2. **Definir.** Propongo una intervención concreta, con alcance, plazos y costo claros antes de empezar.
3. **Construir.** Entrego en ciclos cortos y pruebo cada avance con tu equipo.
